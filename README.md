# Taipei Vanguard — R5 Open City / Characters

版本：**TACTICAL R5 · OPEN CITY**。

這一版直接取代R4。場景不再以高牆包住未使用格子：使用96×72開放地面，真正的建築、車輛、攤位、岩石與看台才產生碰撞。八種景點能看到街廓、廣場、庭院、球場或遠山，不再共用封閉迷宮外觀。

## 場景與角色

- 101：信義街廓、柏油車道、斑馬線、人行道與101；另有透明觀景窗及城市景觀的89F任務。敵人用戰術裝及蒙面便服。
- 夜市：連續店面、中文招牌、騎樓雨棚、攤位、機車、燈籠及入口。敵人有工作服、三種圍裙、便帽／廚師帽。
- 宮廟：廟埕、三川殿、前後院與兩側護龍。虛構幫派角色分花衫、白背心與運動便服，加入金鍊、眼鏡與比例差異。
- 其餘景點分別有開放前庭、庭園展廳、兩廳廣場、棒球場／看台與起伏山路；人物對應都市便服、館內入侵者、工作服及登山裝。
- 人質不持槍、沒有敵人臂帶。便服人物使用新增的CC0骨架模型，原戰術模型保留；都有走／跑、閃避與貼地倒下。跑步會校正鞋底接觸，避免新骨架沉地。

## 如何上傳

**直接解壓完整遊戲ZIP，上傳裡面的檔案與資料夾到GitHub專案根目錄，覆蓋同名檔案。不需要先套任何更新包。**

務必保留assets和vendor資料夾，以及新增的city-scene.js、character-wardrobe.js、character-styles.js與解碼器。本版所有程式、模型和解碼器均在本機檔案內，沒有外部CDN依賴。重新整理後應顯示 **TACTICAL R5 · OPEN CITY**。本交付沒有代為部署網站。

SCENE_DESIGN.html是實際遊戲畫面預覽；SCENE_DESIGN_R5.md列出研究來源、造型與場景邊界。

## 操作與任務

WASD移動、空白鍵跳躍、滑鼠左鍵開火（按住連射）、R換彈、F互動。拆彈需持續按住F四秒；放開、移動、跳躍、開火或中彈會重置進度。觸控FIRE、拖曳瞄準與長按INTERACT保留。

12關救援／拆彈／撤離流程與每關固定敵人名單保留。互動、折返或跨階段不會補生。救援必須帶人質到該關出口。第8、12關的三波防守演練仍需另外選擇。

## 驗證

49項Node檢查通過：開放地面比例、沒有迷宮牆格、12關可達性與實際射擊／過關、角色群、地形高度、拆彈中斷、救援撤離、不補生、可選防守及鍵鼠／觸控。

`node --test tests/desktop-controls.test.cjs tests/route-flow.test.cjs`

Chromium另驗證全部12關的實體遮蔽與過關流程、25個真正變化的便服跑步姿勢及腳底位置、48個倒地貼地案例、樓梯／山坡相機高度、鍵鼠開火／跳躍、電腦與模擬觸控長按拆彈。沒有頁面錯誤或外部執行期請求。記錄在tests/mission-results.tap與tests/site-browser-results.json。

已安裝Playwright和Chrome時可執行`node tests/ambush-browser.cjs`；該測試自行開啟本地測試伺服器，測試控制介面只注入記憶體副本，不在交付遊戲內。流程驗證提高測試護甲，仍需真人檢查難度及實體平板效能。
