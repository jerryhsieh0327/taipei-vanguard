## 本次環境更新

- 路人：八種場景都有不持槍的路人，沿可走路線散步、停留、逛街；聽到附近槍聲會逃離，稍後返回。信義配置14人、故宮12人、夜市16名顧客及6名攤商，其餘各8人；為控制效能，畫面只繪製附近最多8名路人。路人不屬於敵人名單，也不影響過關。
- 汽機車：各景點新增停放汽車／廂型車與機車；汽車增加車窗、輪胎、車燈、保險桿與車牌，機車增加坐墊、握把與後照鏡，均有地面碰撞。
- 夜市：八類商品為胡椒餅、藥燉排骨、蚵仔煎、珍珠奶茶、水果鮮切、豆花甜品、服飾包包與玩具雜貨。以實際立體商品、烤爐、湯鍋、煎台、杯子和托盤呈現，另有六名攤商與十二輛停放機車。
- 故宮：起點移到館外前庭，走上階梯、穿過正門大廳後才開始兩枚炸彈任務，最後回到館外出口。館內有服務台、導覽牆、方向指示、七組玻璃展櫃、瓷器／銅鼎／玉器／文獻示意、原創山水畫、展品標籤、照明與護欄。
- 101：兩關都改在信義百貨步行街區，加入新光三越A9、A11等百貨立面、人行區與周邊道路，從起點能看到完整101。兩關使用不同接近路線、守衛及撤離位置。原89樓關卡已不在本版任務中。

SCENE_DESIGN.html可離線查看11張實際遊戲截圖；SCENE_DESIGN_R6.md列出場景研究與重建範圍。

## 操作與過關

WASD移動、空白鍵跳躍、滑鼠左鍵開火（按住連射）、R換彈、F互動。拆彈需持續按住F四秒；放開、移動、跳躍、開火或中彈會重置。觸控移動、拖曳瞄準、FIRE及長按INTERACT保留。

12關救援／拆彈／撤離流程保留。敵人隨接近區域或轉彎從掩護後出動，每組只啟動一次；互動、折返、跨階段及路人活動不會補生。救援需帶人質抵達該關出口。第8、12關的三波防守演練仍需另行選擇。
