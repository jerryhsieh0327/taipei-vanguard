# Taipei Vanguard — Tactical R4: Site Missions

版本標示：**TACTICAL R4 · SITE MISSIONS**。本版承接R3.1鍵鼠操作與不重生規則，依八個景點的公開場地特色重作可玩配置、敵人部署與任務流程。

## 本次變化

- 不再共用同一條U形接近路線。八種場地拓撲、十二種建議路線與十二組不同守衛部署。
- 101分商場中庭、89F觀景環廊；紀念堂使用池岸／迴廊與階梯兩翼；龍山寺用前後院與兩側護龍；故宮用連接展廳；自由廣場用兩廳與開放交會區；大巨蛋用外圈／球員隧道／球場／看台；夜市用攤列與側巷；陽明山用岩稜／箭竹分支。
- 敵人依位置採守點、短距離衝擊、交叉火力、巡查或沿指定側翼路線移動，保留跑步、閃避、貼圖骨架動畫與地面倒下。
- 救援關必須將人質護送到該關出口，玩家獨自到達不算完成。拆彈關須長按四秒，完成後再撤離。
- 一般戰役固定敵人名單；互動、折返與跨階段都不會生出新敵人。遠處守衛不鎖住任務，附近可見敵人會阻止操作。回程可能遇到尚未驚動的原有守衛。
- 第8、12關保留另外選擇的三波防守演練，不會自動混入一般戰役。

## 操作

電腦：WASD移動、空白鍵跳躍、滑鼠左鍵開火（按住連射）、R換彈、F互動、Esc退出滑鼠鎖定／暫停。點擊視野可鎖定滑鼠。

拆彈時持續按住F或INTERACT四秒。放開、移動、跳躍、開火或中彈會重置進度。炸彈倒數在全部拆除後停止，暫停會凍結倒數。

觸控：左側移動、右側拖曳瞄準，使用FIRE、AIM、RELOAD與INTERACT；拆彈需長按INTERACT。

## 安裝／更新

完整ZIP可直接解壓，上傳檔案與資料夾至GitHub Pages專案根目錄。更新包適用R2、R3或R3.1，依同一路徑覆蓋，務必包含新增的 **site-plans.js**。

不要只上傳ZIP本身，也不要把整份遊戲多包一層資料夾。上傳後重新整理，應顯示 **TACTICAL R4 · SITE MISSIONS**。本交付尚未代為部署網站。

遊戲依賴及模型都在本機檔案內。使用GitHub Pages或本地HTTP伺服器載入；瀏覽器模組不適合以file://直接開啟index.html。

## 查看關卡與研究

開啟 **SCENE_DESIGN.html** 可切換12關碰撞配置，查看路線、炸彈、人質、出口，並選擇是否顯示藏點劇透。**SCENE_DESIGN.md** 列出八個景點的來源、設計決策與實作邊界。

仍為簡化幾何場景，不是攝影測量重建。101樓層分開出勤，未加入可搭乘電梯；山路尚未加入可行走的地形高差。
